# GearHub - маркетплейс компьютерной периферии

## 1. Описание проекта

**GearHub** - это учебный веб-проект, представляющий собой мини-маркетплейс компьютерной периферии и игровых аксессуаров. Сайт предназначен для просмотра каталога товаров, поиска необходимых устройств и добавления товаров в корзину.

Проект разрабатывается для практического изучения веб-разработки, JavaScript и совместной работы с использованием Git и GitHub.

## 2. Цель проекта

Цель проекта - создать удобный и адаптивный веб-сайт для просмотра и выбора компьютерной периферии.

Основные задачи:
- Разработать главную страницу сайта.
- Создать каталог товаров и категории.
- Реализовать поиск товаров.
- Добавить фильтрацию и сортировку.
- Реализовать корзину с возможностью изменения количества товаров.
- Обеспечить корректное отображение сайта на компьютерах и мобильных устройствах.
- Организовать совместную разработку с помощью GitHub.

## 3. Основные функции

- **Главная страница** - описание магазина и отображение категорий товаров.
- **Каталог товаров** - просмотр доступных товаров.
- **Категории** - разделение товаров по типам.
- **Поиск** - поиск товаров по названию.
- **Фильтрация** - отбор товаров по заданным параметрам.
- **Сортировка** - изменение порядка отображения товаров.
- **Карточка товара** - отображение названия, изображения и цены.
- **Корзина** - добавление и удаление товаров, изменение их количества.
- **Избранное** - сохранение выбранных товаров, если функция реализована.
- **Адаптивный интерфейс** - поддержка различных размеров экрана.

## 4. Категории товаров

В каталоге GearHub предусмотрены следующие категории:
- Клавиатуры.
- Компьютерные мыши.
- Наушники и гарнитуры.
- Коврики для мыши.
- Микрофоны.
- Веб-камеры.
- USB-хабы и переходники.

## 7. Установка и запуск

Для запуска проекта необходим современный веб-браузер. Для удобной разработки рекомендуется использовать Visual Studio Code и расширение Live Server.

Порядок запуска:

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/trx333bladd/gearhub.git
   ```

2. Перейти в папку проекта:

   ```bash
   cd gearhub
   ```

3. Открыть папку проекта в Visual Studio Code.

4. Запустить файл `index.html` через Live Server или открыть его непосредственно в браузере.

## 8. Организация командной работы

Проект разрабатывается командой из двух человек.

**Участник 1:**
- Разработка структуры страниц.
- Создание интерфейса с использованием HTML и CSS.
- Адаптивная верстка.
- Подготовка изображений и содержимого страниц.

**Участник 2:**
- Разработка логики на JavaScript.
- Подготовка данных товаров.
- Реализация поиска, фильтрации и сортировки.
- Реализация корзины и проверка её работы.

Оба участника участвуют в интеграции компонентов, тестировании и подготовке проекта к защите.

## 9. Модель разработки

Для организации процесса разработки используется каскадная модель Waterfall.

Этапы разработки:
1. Анализ требований.
2. Проектирование интерфейса и структуры данных.
3. Разработка веб-сайта.
4. Тестирование и исправление ошибок.
5. Подготовка итоговой версии и защита проекта.

## 10. Тестирование

В процессе тестирования проверяются следующие возможности:
- Корректное отображение главной страницы.
- Работа каталога и категорий.
- Поиск товаров по названию.
- Работа фильтрации и сортировки.
- Добавление товаров в корзину.
- Изменение количества и удаление товаров.
- Правильный пересчёт общей стоимости корзины.
- Отображение сайта на мобильных устройствах и компьютерах.

## 11. Возможности дальнейшего развития

В дальнейшем проект можно расширить следующими функциями:
- Регистрация и авторизация пользователей.

## 12. Статус проекта

Проект GearHub находится в разработке и создаётся в образовательных целях.

Базовая версия представляет собой прототип маркетплейса. Реальные платежи, обработка заказов и управление складскими остатками не входят в базовый функционал.
